# Banki Mobile Application | Java, Android Studio, SQLite                                                            (2023)

A fully functional mobile banking application simulating transactions such as withdraw, deposit, bills payment, and transaction history display.

## Features:

- Withdraw: Allows users to withdraw money from their accounts.
- Deposit: Users can easily deposit money into their accounts.
- Bills Payment: Enables payment of bills like electricity and water.
- Transaction History: Displays a list of transactions in chronological order using RecyclerView.
- High Security: Includes biometric authentication (fingerprint recognition) for added security.

## 🛠️ Tools Used:

- Programming Language: Java
- Development Environment: Android Studio
- Data Storage: SQLite
- UI Design: XML (using RelativeLayout and GridLayout for user-friendly interfaces)
- Transaction Display: RecyclerView for dynamic transaction list display

## 🚀 How to Run:

1. Open the project in Android Studio.
2. Build the app and run it on an emulator or a physical device.
3. Test transactions like withdrawal, deposit, or bill payments.
